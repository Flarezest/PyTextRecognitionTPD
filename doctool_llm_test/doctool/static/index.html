    2. Текущий владелец: базовая анкета ↔ заявление
    
  
    Данные заявления пока вводятся вручную. Зелёный — совпадает, красный — расходится, жёлтый — «кем выдан» написан по-разному,
    без цвета — сравнивать не с чем. Сравнение без учёта регистра, ё/е, пробелов и знаков препинания; паспорт и телефон — по цифрам.

    3. Новый владелец (физлицо) → базовая анкета в manager
    
  
    «Заполнить автоматически» можно нажать в любой момент: программа откроет (или найдёт) вкладку manager «Базовая анкета пользователя #…»
    этого аккаунта и заменит в ней поля, которые заполнены здесь; пустые поля не трогает. «Сохранить» в manager нажимаете вы.
    Гражданство и страну почтового адреса выставляете сами; English name пересчитывает сама страница manager.
