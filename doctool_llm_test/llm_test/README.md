# Тестовая сборка 0.7.0.dev2: поля заявления читает модель

Эксперимент, не основная сборка. Рабочая программа в `..\doctool` не менялась.

## Что изменено относительно 0.6.0

- Поля заявления (ФИО, дата рождения, паспорт, «кем выдан», адрес, ИНН, домены, новый администратор, контакты,
  договор, подпись, дата заявления) читает локальная текстовая модель через Ollama, а не регулярки `text:` бланка.
- Модель получает текст заявления: текстовый слой PDF/DOCX или распознанный Tesseract текст скана. Кроме текста,
  она получает описания полей из `forms\regru_transfer_person.yaml` (ключи `llm_context`, `llm_example`, `llm:` у полей)
  и возвращает для каждого поля **дословную цитату**.
- Программа ищет цитату в тексте.
  - Цитата нашлась: значением становится этот кусок документа. Дальше всё как раньше: разбор значения, проверки,
    вердикт.
  - Цитата не нашлась (модель что-то додумала): уверенность значения 0,55, вердикт — «ручная проверка». В замечаниях
    будет «Модель вернула значения, которых нет в тексте…».
  - Домен, которого нет в тексте, остаётся в списке, но попадает в «Домены, прочитанные по-разному».
- Без изменений:
  - определение типа заявления (ключевые слова);
  - паспорт;
  - области на скане и фрагменты;
  - рукопись (VLM);
  - список доменов, перечитанный абзацем.
- Если модель недоступна или не уложилась в предел, поля читаются регулярками. В замечаниях это отмечено.
- В папке дела появляется `llm_debug.json`: какой текст получила модель, что ответила, сколько секунд думала.
  Источник значения в отчёте — `llm-text` / `llm-ocr-text`. Со знаком `?` — значения, которых нет в тексте.

## Как прогнать наборы на своей видеокарте

1. Ollama запущена, модель скачана: `ollama pull qwen3:8b` (около 5,2 ГБ).
2. Запустите `check_llm.bat`. Он прогоняет каждый набор из `Dataset\PhysicalPersonAdminChange` дважды:
   регулярками и моделью (`qwen3:8b`, с рассуждением, предел 4 минуты на обращение).
3. Итог появится в консоли и в файле `results_cmp\llm\сравнение.html`:
   - вердикты двух режимов;
   - время модели;
   - какие поля прочитаны по-разному.

Параметры можно дописать к команде:

- `check_llm.bat --think off` — модель без рассуждения: быстрее;
- `check_llm.bat --sets set8 set13` — только эти наборы;
- `check_llm.bat --skip-regex` — режим регулярок уже прогнан, повторить только модель.

Пока идёт прогон, проверьте в другом окне `ollama ps`: должно быть `100% GPU`. Если там есть процент CPU,
модель не поместилась в видеопамять целиком, и всё будет заметно медленнее.

## Что прислать

Папку `results_cmp` целиком. Если её нельзя отдать, то хотя бы `results_cmp\llm\сравнение.json` и
`results_cmp\llm\*.log`. Кэш ответов модели (`results_cmp\llm_cache`) тоже пригодится: по нему видно
рассуждения модели.

## Веб-интерфейс в режиме модели

Запустите `doctool_web_llm.bat`.

Если включён флажок «рукописное», для рукописи по-прежнему нужна VLM (qwen3-vl). На 8 ГБ видеопамяти две модели
не поместятся одновременно, и Ollama будет их переключать: это лишние секунды на каждое заявление.
