# Сравнение режимов: регулярки бланка и нейросеть (0.7.0)

`check_llm.bat` (в корне программы) прогоняет каждый набор из `Dataset\PhysicalPersonAdminChange` дважды:

- регулярками бланка — как без галки «Поля заявления — нейросетью»;
- нейросетью — как с галкой (по умолчанию `qwen3:8b` с рассуждением, предел 4 минуты на заявление).

Нужно: Ollama запущена, модель скачана (`ollama pull qwen3:8b`). Пока идёт прогон, проверьте в другом окне `ollama ps`:
должно быть `100% GPU`. Если там есть процент CPU, модель не поместилась в видеопамять целиком, и всё будет медленнее.

Итог появится в консоли и в `results_cmp\llm\сравнение.html` (рядом — `сравнение.json`):

- вердикты двух режимов;
- время нейросети;
- какие поля прочитаны по-разному.

Параметры можно дописать к команде:

- `check_llm.bat --think off` — без рассуждения: быстрее, но чаще ошибается;
- `check_llm.bat --sets set8 set13` — только эти наборы;
- `check_llm.bat --skip-regex` — режим регулярок уже прогнан, повторить только нейросеть;
- `check_llm.bat --model qwen3-vl:8b-instruct` — другая модель (например, та же, что для рукописи: тогда Ollama не
  переключает модели в видеопамяти).

В папке каждого дела, прочитанного нейросетью, есть `llm_debug.json`: какой текст получила модель, что ответила, что
программа отбросила и почему, сколько секунд это заняло. Ответы кэшируются в `.llm_cache` папки результатов:
повторный прогон того же текста модель не вызывает.
